Немає звуку в навушниках у Windows: що робити

Навушники підключені, а звук іде в колонки або його немає зовсім. Найчастіше проблема вирішується за хвилину — перевірте пункти по черзі.

1. Перевірте, куди Windows виводить звук

Найчастіша причина: звук іде на інший пристрій — колонки, монітор через HDMI або стару гарнітуру.

  1. У Windows 11 натисніть Win + A, потім стрілку «>» поруч із повзунком гучності.
  2. У Windows 10 клацніть по значку динаміка в треї та натисніть на назву пристрою над повзунком.
  3. Оберіть навушники.

2. Перевірте гучність застосунку

Звук може бути вимкнений лише в однієї програми. Відкрийте Параметри → Система → Звук → Мікшер гучності і переконайтеся, що повзунок потрібного застосунку не на нулі, а звук не вимкнено.

3. Перепідключіть навушники

  • Дротові — вийміть штекер і вставте знову; спробуйте інший роз'єм (наприклад, на задній панелі ПК).
  • Bluetooth — відключіть і знову підключіть навушники в Параметри → Bluetooth і пристрої.
  • USB — підключіть в інший USB-порт.

4. Запустіть засіб усунення неполадок

У Windows 11: Параметри → Система → Усунення неполадок → Інші засоби усунення неполадок → Звук. У Windows 10: Параметри → Оновлення й безпека → Усунення неполадок. Засіб сам перевірить пристрої та служби.

5. Перезапустіть службу Windows Audio

  1. Натисніть Win + R, введіть services.msc і натисніть Enter.
  2. Знайдіть Windows Audio, натисніть правою кнопкою → Перезапустити.

6. Оновіть або перевстановіть драйвер

Відкрийте Диспетчер пристроїв (правий клік по «Пуску»), розгорніть «Звукові, ігрові та відеопристрої», натисніть правою кнопкою на звукову карту → Оновити драйвер. Якщо не допомогло — Видалити пристрій і перезавантажте ПК: Windows встановить драйвер заново.

Часті питання

Чому звук іде в колонки, хоча навушники підключені?

Windows не завжди сама перемикає пристрій за замовчуванням. Оберіть навушники вручну у списку пристроїв виведення.

Навушники видно у списку, але звуку немає. Що робити?

Перевірте гучність конкретного застосунку в мікшері, потім перезапустіть службу Windows Audio та оновіть драйвер.
