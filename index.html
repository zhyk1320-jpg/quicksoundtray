FAQ

Частые вопросы

Это правда бесплатно?

Да. Никакой рекламы, подписок и регистрации.

Почему Windows предупреждает при запуске?

SmartScreen показывает предупреждение для новых программ, у которых ещё мало загрузок. Нажмите «Подробнее» → «Выполнить в любом случае». Контрольную сумму файла можно сверить в разделе «О приложении».

Какие системы поддерживаются?

Windows 10 и Windows 11, 64-бит. Дополнительно ничего ставить не нужно.

Собирает ли приложение данные?

Нет. Приложение не отправляет данные в сеть. Все настройки хранятся локально в %LOCALAPPDATA%\QuickSoundTray.

Чем отличаются два установщика?

Основной ставит программу только для вашего пользователя и не требует прав администратора. Второй ставит для всех пользователей компьютера.

Конфиденциальность

QuickSoundTray не собирает, не хранит на серверах и не передаёт никакие персональные данные. Приложение не содержит аналитики и рекламы.

Все настройки хранятся локально на вашем компьютере в папке %LOCALAPPDATA%\QuickSoundTray и удаляются вместе с приложением.
